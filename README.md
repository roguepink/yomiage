# よみあげ

文章をはりつけると、スマホの声で読み上げてくれる、無料のアプリです。

**遊ぶ: https://roguepink.github.io/yomiage/**

## LINE で送る・ホーム画面に入れる

- 上のアドレスを LINE に貼れば、タイトルと絵つきの紹介が出る。タップするとすぐ遊べる
- **LINE の中で開いたときは、ホーム画面に入れられない。**メニューから「Safari で開く」(iPhone)/「他のアプリで開く」→ Chrome(Android)を選んでから入れる
  - iPhone(Safari): 共有ボタン →「ホーム画面に追加」 / Android(Chrome): メニュー(︙)→「アプリをインストール」
- 入れたあとは全画面で起動。一度開けば電波がなくても遊べる

## 直して公開するとき

- `main` に push すれば公開される(GitHub Pages)。電波のある人は、**次に開いたとき**に新しい版になる(`sw.js` は まずネットで最新を取りにいく)
- `sw.js` の `VERSION` を上げるのは、覚えるファイル(`FILES`)を変えたときだけ

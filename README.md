# よみあげ

文章をはりつけると、スマホの声で読み上げてくれる、無料のアプリです。

**遊ぶ: https://roguepink.github.io/yomiage/**

## LINE で送る・ホーム画面に入れる

- 上のアドレスを LINE に貼れば、タイトルと絵つきの紹介が出る。タップするとすぐ遊べる
- **LINE の中で開いたときは、ホーム画面に入れられない。**メニューから「Safari で開く」(iPhone)/「他のアプリで開く」→ Chrome(Android)を選んでから入れる
  - iPhone(Safari): 共有ボタン →「ホーム画面に追加」 / Android(Chrome): メニュー(︙)→「アプリをインストール」
- 入れたあとは全画面で起動。一度開けば電波がなくても遊べる

## 直して公開するとき

- `main` に push すれば公開される(GitHub Pages)。電波のある人は、**次に開いたとき**に新しい版になる(`sw.js` は まずネットで最新を取りにいく)
- `sw.js` の `VERSION` を上げるのは、覚えるファイル(`FILES`)を変えたときだけ

## 2026-11-13 追加した6つ(枝 kaizen)
1. **共有で読む**: manifest の `share_target`(GET `./?title=&text=&url=`)。インストールした Android だけ。アドレスだけ届いたときは「文字を選んで共有して」と出す(ページの中身は取りに行かない)
2. **おやすみタイマー**: 15分〜1時間半。文の切れ目ごとと15秒ごとに時刻を見て止める
3. **10秒もどる・前の文・次の文**: 10秒は「1秒に6.5字×速さ」で見積もる。ロック画面の前後ボタンも同じ
4. **読み方の直し**(⚙設定): `yomi.dict` に {字, 読み}。長い字から先に置きかえる。画面の字はそのまま
5. **本棚**: `yomi.books`(文章・どこまで読んだか)。前の版の `yomi.text` は自動で引っこし
6. **文字の大きさ**(⚙設定): 5段階。`--fs`
- 試し方: 音は出さず、読み上げをまねる仕組みで確かめる(Mac で実音を出さない)
